Kein Overhead, keine Vendor-Abhängigkeit. Läuft auf einem 20€-VPS genauso wie auf deinem NAS.

🤖

Boss + Worker Agenten

Ein Boss-Agent koordiniert mehrere Worker. Aufgaben werden aufgeteilt, parallel ausgeführt und die Ergebnisse zusammengeführt.

🔀

Multi-LLM pro Agent

Jeder Agent nutzt sein eigenes Modell: Claude (OAuth), MiniMax, Ollama oder andere OpenAI-kompatible APIs. Mischbetrieb möglich.

💻

Web Console

React-basierte Dark-Mode-UI. Streaming, Tool-Call-Anzeige, Agenten-Verwaltung, Admin-Bereich — alles im Browser.

🧠

Memory & Skills

Agenten speichern Wissen in Markdown-Dateien, die automatisch in jede Session injiziert werden. Skills erweitern das Verhalten per hot-reload.

🔧

Shell-Exec (3 Modi)

Safe, Elevated oder Unrestricted — du bestimmst wie viel Systemzugriff ein Agent bekommt. Blocklist für kritische Kommandos inklusive.

🎙️

Voice

TTS und STT über MiniMax oder lokale Engines (Coqui, Wyoming). Agenten können sprechen und zuhören.

📱

Telegram & WhatsApp

Jeder Agent ist optional als Telegram-Bot erreichbar. WhatsApp-Bridge per Projekt konfigurierbar.

🔌

MCP-Support

Model Context Protocol: externe Tools und Datenquellen werden als MCP-Server eingebunden. Über 70 Tools direkt verfügbar.

📦

One-Command Install

Ein Bash-Script richtet alles ein: systemd-Service, nginx, SQLite, Verzeichnisstruktur. In unter 5 Minuten betriebsbereit.

Los geht's

Einen Befehl. Fertig.

Funktioniert auf Ubuntu 22.04 / 24.04. Root oder sudo erforderlich.

bash
# HydraHive installieren curl -sSL https://raw.githubusercontent.com/hydrahive/hydrahive/main/installer/install.sh | bash # Danach: Browser öffnen → http://<dein-server>
