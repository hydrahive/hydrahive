Boss + Worker Swarm

One Boss-Agent per project coordinates a pool of specialists. Parallel task dispatching, aggregated results.

🔌

Plug & Play Installation

One curl command. GPU auto-detected. Services configured. Web console ready in minutes.

💬

Matrix-based Communication

Agents communicate via Matrix rooms. Use Element to jump in and supervise any conversation live.

🤖

Multi-LLM per Agent

Each agent runs its own model. Ollama locally, Claude API, OpenAI — mixed per task. Graceful fallback built-in.

📁

Project File Shares

Each project gets a Linux user, isolated filesystem, and automatic Samba share. Agents and clients share data natively.

🔒

Defense in Depth

Three-layer tool permission model. Agents can only use what the Core Registry allows — regardless of their config.

Deployment Profiles

Start small. Scale to full GPU when ready.

🔵 Lite

Cloud APIs · No GPU required
  • VM or VPS — any hardware
  • Claude API + OpenAI
  • Full web console
  • Matrix communication
  • All project features

🟣 Full

Local LLMs · GPU Passthrough
  • PCIe GPU passthrough (e.g. GTX 1080)
  • Ollama — llama3.1:8b default
  • No API costs for local tasks
  • Hybrid: local + cloud per agent
  • Auto-detected at install time
